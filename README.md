# FitnessCRM

FitnessCRM is focused on helping fitness businesses manage clients, programs, and communication in one place.

## Product goal

Build a simple, reliable CRM experience for gyms, coaches, and wellness teams so they can spend less time on admin tasks and more time supporting members.

## Repository overview

The repositories in this organization are organized to support the full FitnessCRM platform, including:

- **Application repositories** for customer-facing product features.
- **API and backend repositories** for business logic, integrations, and data management.
- **Shared tooling and automation repositories** (like this `.github` repository) for workflows, templates, and engineering standards used across projects.
